**What's new in 1.4.0**

- Settings: a simpler first view. The Ratings database section now holds only the status line, Update now and Refresh automatically, so a new install has one thing to do.
- Settings: everything OMDb (Use OMDb, the key, the Rotten Tomatoes, Metacritic and awards options, and OMDb only, now a single tick) is in a fold named OMDb. It opens by itself if you already use OMDb.
- Nothing else changes: the same settings, the same permissions.

Download the ZIP, extract it, then in Chrome open chrome://extensions, turn on Developer mode, click **Load unpacked** and pick the `show-imdb-ratings` folder. Details in the [README](https://github.com/Lwolf12/show-imdb-ratings#readme).
