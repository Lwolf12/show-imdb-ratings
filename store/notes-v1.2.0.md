**What's new in 1.2.0**

- Titles in other languages (opt-in). A streaming site in another language shows translated titles, which the database knew only by their English and original names, so they got no rating. Tick "Match titles in other languages" in the settings, tick the languages you use (your browser's language and any seen on a streaming page come pre-ticked), and click Get titles: the extension reads IMDb's list of titles by country once (520 MB pass through, nothing saved as a file) and keeps the useful part, about 50 MB, in the database. Ticking another language later takes seconds. Languages written in the Latin alphabet. Not needed with an English browser on English pages.
- Cancel. A build or update in progress can be cancelled from the settings: a download stops at once with nothing changed, and a save stops with the database left consistent.
- HBO Max moved its web app to www.hbomax.com, so the extension now covers that address. Chrome asks once, after this update, to allow the new site: click Accept, or the extension stays off until you do. In Firefox, if HBO Max shows unticked in the settings, tick it to grant the site.
- Settings: the OMDb box is now "Use OMDb", the switch for everything OMDb (lookups of titles the database lacks, episode lists, the Also show scores); choosing OMDb only turns it on. A new "IMDb rating per OMDb" box under Also show adds OMDb's copy of the rating when it differs from the database's. The window is a little wider and nothing on it shifts when you click.
- Paramount+: badges on the home banner's poster strip, a rating chip on a film's own page, and clip cards named "Show - Episode" rated as the show.
- Fixes: a title listed as "Part 1" where IMDb names the first part plainly now matches; a pending Get titles no longer stalls the weekly ratings pass; a failed refresh of the languages list no longer fails an otherwise finished build; the first build reads the languages list when languages are already ticked.

Download the ZIP, extract it, then in Chrome open chrome://extensions, turn on Developer mode, click **Load unpacked** and pick the `show-imdb-ratings` folder. Details in the [README](https://github.com/Lwolf12/show-imdb-ratings#readme).
