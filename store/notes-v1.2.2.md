**What's new in 1.2.2**

- Titles in other languages now covers other scripts: Korean, Japanese, Chinese, Russian, Ukrainian, Bulgarian, Greek, Hebrew, Arabic, Thai and Hindi join the list under Match titles in other languages. Titles in those scripts are matched character for character, and a title's original name in its own script counts too, so a Korean series on a Korean Netflix profile gets its rating like any other.
- If you set languages up before this version and tick one of the new ones, the settings show Get titles instead of Apply once: the list kept from before has no rows for these scripts, so it is read again (520 MB pass through, as the first time). Languages ticked before keep working meanwhile.
- Nothing changes for anyone who does not use the option.

Download the ZIP, extract it, then in Chrome open chrome://extensions, turn on Developer mode, click **Load unpacked** and pick the `show-imdb-ratings` folder. Details in the [README](https://github.com/Lwolf12/show-imdb-ratings#readme).
